- 从主报告读取项目约束、代码准入标准、重点模型风险和未完成线索，再确定新的任务范围。
- 历史正文中的 Windows 路径只是来源记录；当前材料按本页相对链接读取。不要为了更新路径而改写已经保留的原始报告。

- 第三方论文的高 OA 不等于本项目能复现；文献候选不等于项目已经集成。源码公开与复用许可证分别核实。

- 后续增补采用新的日期记录并在本页链接；只有核实并修订结论时才明确更新主报告版本，避免多份同名“最终版”并行。
