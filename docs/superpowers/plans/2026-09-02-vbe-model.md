# VBE-Net Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the complete trainable VBE-Net model class on top of the verified Bures geometry solver.

**Architecture:** One self-contained `models/vbe_net.py` defines two modality-specific stems, five resolution-preserving semi-shared residual blocks, grouped OAS Gaussians, SPD/Bures operations, learnable class prototypes, the variational solver, and final logits.

**Tech Stack:** Python, PyTorch, `unittest`.

**Spec:** `docs/superpowers/specs/2026-09-01-vbe-net-design.md`

## Global Constraints

- Inputs default to MS `[B,10,11,11]` and SAR `[B,4,11,11]`.
- Width is 64, encoder depth is 5, shared channel-mixer expansion is 4, Gaussian groups are 8, and group dimension is 8.
- Every block has modality-private depthwise `3x3` convolution and LayerNorm parameters, but one shared pair of pointwise `1x1` channel mixers.
- There is no spatial downsampling, attention, concatenation classifier, learned gating MLP, residual classifier, or auxiliary loss.
- Geometry runs in FP32 under autocast and is implemented in the same file as `VBENet`.
- Default logits are `-energy / 0.1`; ordinary `forward(ms,sar)` returns only logits for compatibility with existing training loops.
- Training-only modality dropout defaults to 0.1 and removes one modality from the same solver rather than adding a missing-modality branch.

```python
def test_encode_tokens_preserves_full_spatial_grid(self):
    model = tiny_model()
    ms_tokens, sar_tokens = model.encode_tokens(torch.randn(2, 10, 11, 11), torch.randn(2, 4, 11, 11))
    self.assertEqual(ms_tokens.shape, (2, 121, 16))
    self.assertEqual(sar_tokens.shape, (2, 121, 16))

def test_forward_returns_class_logits_and_details(self):
    output = tiny_model().eval()(ms_patch(), sar_patch(), return_details=True)
    self.assertEqual(output.logits.shape, (2, 5))
    self.assertEqual(output.energy.shape, (2, 5))
    self.assertEqual(output.responsibility.shape, (2, 5, 2))
    torch.testing.assert_close(output.logits, -output.energy / 0.1)

def test_backward_reaches_inputs_and_prototypes(self):
    model = tiny_model().train()
    ms, sar = ms_patch(requires_grad=True), sar_patch(requires_grad=True)
    model(ms, sar).sum().backward()
    for gradient in (ms.grad, sar.grad, model.prototype_mean.grad, model.prototype_raw_tril.grad):
        self.assertIsNotNone(gradient)
        self.assertTrue(torch.isfinite(gradient).all())

def test_training_modality_dropout_uses_single_observation(self):
    model = tiny_model(modality_dropout=1.0).train()
    details = model(ms_patch(), sar_patch(), return_details=True)
    self.assertEqual(details.responsibility.shape[-1], 1)
    self.assertEqual(tiny_model(modality_dropout=1.0).eval()(ms_patch(), sar_patch(), return_details=True).responsibility.shape[-1], 2)
```

```python
u_ms = ms + private_ms_dw(private_ms_norm(ms))
```
