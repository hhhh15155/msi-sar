## 本轮判断

1. FDMF 相比 FCM–FFM 的 OA 差值（百分点）：YRD 0.0014、YRD2509NEW +0.5711、GRSS07 +0.0671。YRD几乎持平，GRSS07也仅小幅差异；这两个数据集FCM–FFM的AA／Macro-F1仍略高，不能笼统称FDMF全面最好。YRD2509NEW上FDMF的OA和Macro-F1都更高，值得保留为候选。
2. 首先保留 FCM–FFM 与 FDMF 两个主候选。现有完整V6约6.73M参数，FCM–FFM约2.57M，FDMF约2.69M，MSAF约0.054M（以YRD为例）。V6在这三个数据集未显示精度优势；MSAF更适合作轻量结构对照。本轮不支持直接断言频域机制普遍有效，也不支持归因于某单一修复。
3. 后续优先在相同编码器下比较FCM–FFM／FDMF，并分别取消V6第二级融合与反馈以定位冗余；目前只是分析建议，没有启动额外实验或多种子。稳定性验证应另行确定，不能将一次结果当最终论文结论。
4. YRD SAR-only OA58.03%、AA37.88%、Macro-F1 16.64%，虽不再全图单类预测，仍有两类无预测输出；SAR分支的类别平衡和训练拟合仍需检查，不能仅凭OA认定问题已经解决。
